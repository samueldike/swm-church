{# Telegram bot #}

Telegram bot & channel

{{ secret_field('Telegram bot token', 'telegram_bot_token', secret_status.telegram_bot_token, placeholder='123456789:AAE…') }} {{ field('Telegram audio chat / channel ID', 'telegram_audio_chat_id', value=S.get('telegram_audio_chat_id') or '', mono=True, placeholder='@channelname or -100…') }}
How do I get a bot token and channel ID?
  1. In Telegram, open @BotFather and send /newbot. Choose a display name, then a username ending in bot (e.g. swmaudio_bot).
  2. BotFather replies with a token like 123456789:AAE…. Paste it into Telegram bot token. Treat it like a password: anyone with it can post as your bot.
  3. Open your channel → Administrators → Add admin, search for your bot and allow Post messages.
  4. Channel ID: for a public channel type @yourchannel. For a private one, forward any channel post to @userinfobot ; it shows an ID starting with -100.
  5. Save settings, then press Test connection. It names the bot and the channel it will post to.
{# Large files #}

Large files · up to 2 GB per message

{% if tg_large.on %}{{ badge('On · up to 2 GB', 'ok') }}{% elif tg_large.keys_saved %}{{ badge('Off · keys saved', 'warn') }}{% else %}{{ badge('Off · up to 50 MB', 'neut') }}{% endif %}

Telegram's standard service accepts files up to 50 MB (about 55 minutes of audio at 128 kbps). Large files runs Telegram's official Bot API server on your own server, so sermons up to 2 GB go to Telegram exactly as uploaded. It needs two values from the church's Telegram account: App api_id and App api_hash.

  1. Bot token saved
  2. api_id & api_hash saved
  3. Large files turned on
{% if not tg_large.installed %}
The large-file service is not installed on this server yet. You can save the keys now; turning large files on needs the telegram-bot-api container deployed.
{% endif %}
Step-by-step: get your App api_id and App api_hash (about 3 minutes)
1 · Sign in to my.telegram.org 2 · API development tools Telegram's official guide
  1. Sign in at my.telegram.org with the phone number of a Telegram account the church controls, in international format (e.g. +234 803 123 4567). The login code arrives inside the Telegram app as a message from “Telegram”, not by SMS.
  2. Click API development tools (or open my.telegram.org/apps ).
  3. If you see Create new application, fill it in and click Create application:
    • App title: Scent of Water Uploads (any name)
    • Short name: swmuploads (5–32 letters and digits, no spaces)
    • URL: leave empty · Platform: Other · Description: optional
    If the account already has an application, Telegram shows its details straight away. Use those; an account can only have one.
  4. Copy App api_id (a number, e.g. 1234567) and App api_hash (32 letters and digits) into the boxes below, then press Save settings at the bottom of the page.
  5. Press Turn on large files. The site first checks that Telegram accepts the keys, which takes up to 30 seconds, and only then switches over. Nothing changes if the check fails.

If my.telegram.org shows “ERROR” when creating the app

This is common and almost never about you. Turn off any VPN or ad blocker, use a regular browser window (Chrome or Firefox, not a private one), keep the title and short name plain letters, and try again after a few minutes.

Keeping them safe

They are stored encrypted, are never shown again (only the last four characters), and only the HQ Administrator can change them. They identify the Telegram account, so use one the church will keep: if that account is deleted, large files stop until new keys are saved. They do not give anyone access to the account's chats.
